VD Azur Conseil — сайт на трёх языках (RU / FR / EN)
=====================================================

СТРУКТУРА
  index.html        — выбор языка + автопереход (по языку браузера или прошлому выбору)
  ru/ fr/ en/       — по 6 страниц: index, services, about, faq, contacts, legal
  assets/style.css  — общий файл стилей
  images/           — логотип (монограмма VD), фото команды, иконки
  video.html        — 20-секундный ролик (язык берётся из ссылки ?lang=ru|fr|en)

КАК ОПУБЛИКОВАТЬ
  Залейте ВСЮ папку на хостинг как есть (структуру папок не менять).

ОБЯЗАТЕЛЬНО ЗАПОЛНИТЬ ДО ЗАПУСКА
  Файлы */legal.html — места, выделенные жёлтым [ ... ]:
  форма компании, адрес, SIRET, ответственное лицо, хостинг, дата.
  (Mentions légales обязательны для французского сайта.)

ЖЕЛАТЕЛЬНО
  1. Почта на своём домене вместо gmail (contact@ваш-домен).
  2. Когда будет домен — заменить в <head> ссылки hreflang на полные адреса
     (https://ваш-домен/fr/index.html и т. д.) и добавить сайт в Google Search Console.
  3. Список партнёров (блок «Один контакт — целая сеть специалистов»)
     — оставить только те категории, с которыми вы реально работаете.
  4. Если бесплатная 15-минутная консультация не подходит — убрать фразу
     (hero_note, cta_p и вопрос в FAQ).
